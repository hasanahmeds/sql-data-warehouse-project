# sql-data-warehouse-project
Welcome to Datawarehouse Analytics project repository
The SQL Data Warehouse Project is a comprehensive, hands-on data engineering initiative designed to build a modern SQL data warehouse from scratch using SQL Server. It focuses on extracting data from multiple source systems (CRM and ERP provided as CSV files), cleaning and transforming data quality issues, and integrating disparate sources into a single, user-friendly data model optimized for analytical reporting and informed decision-making.

Following the modern Medallion architecture approach, the project structures the data warehouse into distinct Bronze (raw, untouched data), Silver (cleansed and standardized data), and Gold (business-ready data using a star schema) layers. It implements robust ETL/ELT pipelines, data governance practices, and automated data quality checks, providing a professional portfolio piece that mirrors real-world data warehousing implementations in modern enterprises
